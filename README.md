# دفتر من

حسابداری شخصی با تقویم شمسی، همگام‌سازی زنده میان دستگاه‌ها و خانوار مشترک —
ثبت سادهٔ درآمد و هزینه، حساب‌ها، طلب و بدهی و بودجهٔ ماهانه.

- **سازنده:** میثم ایجادی — توسعه‌دهندهٔ مستقل
- **نسخهٔ فعلی:** 2.1.0 — تاریخچهٔ کامل در [`docs/CHANGELOG.md`](./docs/CHANGELOG.md)
- **درباره و نسخه‌ها در خود برنامه:** مسیر `/about`

## امکانات

- ثبت درآمد و هزینه با مبلغ، تاریخ شمسی، دسته‌بندی، حساب و یادداشت
- انتقال پول میان حساب‌های خودتان — بدون اثر بر درآمد و هزینه
- دسته‌بندی‌های قابل‌تعریف با رنگ و بودجهٔ ماهانه
- چند حساب (نقدی، بانکی، کارت، کیف پول) با موجودی مستقل و تراز کل
- دفتر طلب و بدهی با تسویهٔ یک‌ضرب
- پرداخت‌های تکراری (اشتراک، اجاره، قسط) با ثبت خودکار سرسید
- پیوست تصویر رسید به تراکنش‌ها
- **خانوار مشترک**: یک دفتر واحد برای همهٔ اعضای خانواده — دعوت با کد
  شش‌حرفی، نشان «ثبت‌کننده» کنار هر سند، مدیریت کامل توسط مالک
- نمودار دسته‌ها، روند شش‌ماهه و نمای سالانه
- جست‌وجو و فیلتر، خروجی CSV و پشتیبان JSON کامل
- تم تیره و روشن، اعداد فارسی، واحد تومان/ریال
- همگام‌سازی زندهٔ داده میان همهٔ دستگاه‌ها

## معماری

| لایه | فناوری |
|---|---|
| رابط کاربری | React 19 + Vite + Tailwind ۴ + Radix UI |
| بک‌اند و پایگاه داده | Convex (توابع + جدول‌ها + احراز هویت) |
| احراز هویت | کد یک‌بارمصرف ایمیلی با SMTP خودتان — بدون سرویس واسط |
| استقرار | تصویر داکر ایستا (Nginx) یا هر هاست ایستای دیگر |
| نسخهٔ بومی | اندروید با Capacitor · ویندوز با Tauri |

پروژه به هیچ پلتفرم میزبانی اپی وابسته نیست؛ کل مخزن مستقل است و روی هر
سرور یا رجیستری‌ای قابل انتشار.

## اجرا و توسعه

```bash
bun install
# متغیر VITE_CONVEX_URL را در .env.local تنظیم کنید (نمونه: .env.example):
#   VITE_CONVEX_URL=https://<YOUR-CONVEX>.convex.cloud
bunx convex dev --once        # استقرار بک‌اند + بازتولید تایپ‌ها
bun run dev
```

متغیرهای SMTP را در داشبورد Convex (Settings → Environment Variables) ثبت
کنید تا کد ورود ایمیلی کار کند: `SMTP_HOST`، `SMTP_PORT`، `SMTP_USER`،
`SMTP_PASSWORD`، `OTP_FROM`. نمونه در [`.env.example`](./.env.example).

بررسی سلامت پیش از انتشار:

```bash
bun x tsc -b --noEmit && bun run lint && bun run build
```

## استقرار با داکر

راهنمای کامل و نسخه‌به‌نسخه: [`docs/DOCKER.md`](./docs/DOCKER.md)

```bash
docker build --build-arg VITE_CONVEX_URL="…" -t meysam8498/daftaram:2.1.0 .
docker run -d -p 8080:80 --restart unless-stopped meysam8498/daftaram:2.1.0
```

انتشار خودکار روی GHCR با هر برچسب `vX.Y.Z` — پیکربندی در
[`.github/workflows/docker.yml`](./.github/workflows/docker.yml).

## نسخه‌های بومی

راهنمای کامل ساخت اندروید (APK) و ویندوز (MSI/EXE):
[`docs/NATIVE.md`](./docs/NATIVE.md)

```bash
# اندروید — اجرا روی دستگاه متصل
bun run cap:run:android

# ویندوز — پنجرهٔ بومی در حالت توسعه
bun run tauri:dev
bun run tauri:build   # بستهٔ MSI و NSIS
```
